# 정치·시사 커뮤니티 여론 모니터링 시스템 (POLI-RADAR)

대한민국 주요 6대 시사·정치 커뮤니티(**에펨코리아, 보배드림, 더쿠, 다모앙, 딴지일보, 잇싸**)를 실시간 모니터링하여, 정치 현안에 대한 각 커뮤니티의 반응(스탠스), 감성 지수, 요약, 그리고 **상위 5개 인기 댓글(Best Comments)**을 수집하고 AI로 교차 분석하는 웹 애플리케이션입니다.

## 🚀 주요 기능

1. **실시간 인기글 & 상위 5개 인기 댓글 수집**:
   - 각 커뮤니티의 실시간 핫게시글 및 추천수 기반 상위 5개 댓글(Best 댓글) 수집
2. **LLM/AI 기반 현안 자동 추출 및 스탠스 분석**:
   - Gemini AI 연동을 통해 여러 커뮤니티의 게시글을 묶어 핵심 정치 현안(Issue)으로 클러스터링
   - 각 커뮤니티별 여론 스탠스(적극 지지 / 강한 비판 / 중립 등), 감성 지수(-1.0 ~ +1.0), 3줄 요약, 핵심 키워드(#) 자동 생성
3. **인터랙티브 비교 대시보드**:
   - 현안별 6대 커뮤니티 반응 카드 그리드 비교
   - 성향별 필터링 (보수 vs 진보 vs 여성층)
   - 원문 게시글 및 상위 5개 댓글을 직접 확인할 수 있는 탐색 모달 지원
4. **원클릭 실시간 동기화**:
   - 웹 대시보드 상단 '지금 여론 새로고침' 버튼으로 언제든지 최신 데이터 수집 및 AI 재분석 실행

## 🛠️ 실행 방법

### 백엔드 실행 (API & 정적 웹 서빙)
```bash
cd backend
python run.py
```
> 브라우저에서 `http://localhost:8000` 접속 시 통합 웹 대시보드가 열립니다.

### 프론트엔드 개발 서버 (옵션)
```bash
cd frontend
npm run dev
```
> `http://localhost:5173` 접속 (8000번 백엔드 포트로 자동 프록시)

### 환경 변수 설정 (선택 사항)
Gemini AI 실시간 API 분석을 사용하려면 `.env` 파일에 API 키를 설정할 수 있습니다. (키가 없어도 내장된 인텔리전트 분석 엔진으로 완벽하게 동작합니다):
```env
GEMINI_API_KEY=your_gemini_api_key_here
```
